# Инвестиционный калькулятор

Веб-приложение для расчёта инвестиционного дохода с учётом налогов, инфляции, реинвестирования и дополнительных вложений.

## Возможности

- Расчёт сложного процента с разными периодами реинвестирования (ежедневно, ежемесячно, ежеквартально, раз в полгода, ежегодно)
- Единичные и периодические дополнительные вложения
- Учёт налога на доход и инфляции
- Таблица и график структуры капитала по периодам
- Показатели в номинальном и реальном выражении

## Технологии

- **Backend**: Go (net/http, clean architecture)
- **Frontend**: React + TypeScript + Vite
- **UI**: Vanilla CSS (dark theme)

## Запуск

### Локально

```bash
# Сборка фронтенда
cd web
npm install
npm run build

# Запуск сервера
cd ..
go run ./cmd/server
```

Сервер доступен по адресу `http://localhost:8080`.

### Docker

```bash
docker build -t invest-calc .
docker run -p 8080:8080 invest-calc
```

## Структура проекта

```
├── cmd/server/           — точка входа
├── internal/
│   ├── domain/           — модели и интерфейсы
│   ├── infrastructure/   — хранилище (memory store)
│   ├── interfaces/http/  — HTTP handler + embed статика
│   └── usecases/         — бизнес-логика расчёта
└── web/                  — React фронтенд
    └── src/
        ├── components/   — UI компоненты
        └── types.ts      — общие типы
```
